## Verdict rule

Grade every rubric check as `pass`, `fail`, or `unclear` based on the available evidence.

- `pass`: The evidence satisfies the check's pass condition.
- `fail`: The evidence contradicts the pass condition, or a mandatory artifact, test, or action is demonstrably missing.
- `unclear`: The available evidence is insufficient to determine whether the pass condition is satisfied.

Return `accept` only if every `required` check receives `pass`.

Return `reject` if any `required` check receives `fail` or `unclear`.

`preferred` checks must still be evaluated and reported, but their grades do not affect the final verdict.

Do not invent missing evidence, treat unsupported claims as verified facts, or reject solely because an honestly disclosed limitation exists. Assess whether the limitation prevents the PR from satisfying a required check.
